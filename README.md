# 2023 AIFFEL 학습 기록

Python 기초부터 데이터 분석, 머신러닝, 신경망과 생성형 모델까지, 2023년 AIFFEL 과정에서 진행한 실습과 동료 리뷰를 모아 둔 기록입니다. 당시의 코드, 실행 결과와 시행착오를 보존합니다.

## 기록을 읽을 때

교육용 예제와 과제 지시문, 직접 작성한 코드와 동료 리뷰가 함께 들어 있습니다. 노트북 출력은 당시의 실행 기록이며, 현재 환경에서 재실행해 검증한 결과는 아닙니다. 일부 데이터는 당시 환경의 경로나 심볼릭 링크에 의존하고, 실습 중 오류와 미완료 셀도 남아 있습니다. 각 실습의 구현 범위와 확인 가능한 결과는 상세 기록에 정리했습니다.
